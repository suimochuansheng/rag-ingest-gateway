# 智能文档解析平台 - 用户手册

## 概述

智能文档解析平台（以下简称“平台”）是一款基于 AI 的文档理解工具，支持 PDF、Word、Excel、Markdown 等 10+ 种格式的自动解析与结构化提取。

## 功能列表

| 功能模块 | 描述 | 支持格式 | 准确率 |
| :--- | :--- | :--- | :--- |
| 文本提取 | 提取文档中的纯文本内容 | PDF, DOCX, TXT | 99.5% |
| 表格识别 | 自动识别并提取表格结构 | PDF, DOCX, XLSX | 96.2% |
| 图片描述 | 生成图片内容的自然语言描述 | PDF, DOCX | 92.0% |
| OCR 识别 | 对扫描件进行文字识别 | 扫描 PDF | 93.5% |
| 版面分析 | 识别标题、段落、页眉、页脚 | PDF, DOCX | 98.1% |

## 操作指南

### 上传文档

1. 点击“新建解析任务”按钮
2. 选择本地文档（单次最大支持 100MB）
3. 选择解析模板（标准/财务/法律/学术）
4. 点击“开始解析”

### 查看结果

解析完成后，可在“任务列表”中查看结果，包括：
- 提取的纯文本
- 识别出的表格（可导出为 Excel）
- 自动生成的文档摘要
