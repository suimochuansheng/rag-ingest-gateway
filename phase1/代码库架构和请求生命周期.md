   ## 第三部分：核心分支逻辑与开关

   ### 3.1 条件分支一览

   【分支1】Loader 路由 — 根据文件扩展名选择解析器
     位置: ingest_knowledge.py:128-139
     逻辑:
       ext = file_path.split(".")[-1].lower()
       loader_map = {
           "pdf":  PDFLoader(),
           "docx": DocxLoader(),
           "xlsx": ExcelLoader(),
           "md":   MarkdownLoader(enable_caption=True, fail_on_caption_error=...),
           "txt":  MarkdownLoader(enable_caption=True, fail_on_caption_error=...),
       }
       loader = loader_map.get(ext)   ← 未匹配时打印错误并 return
     无法覆盖的格式: .html, .rst, .csv 等会触发 "❌ 不支持的文件格式"

   【分支2】图片描述失败策略 — fail_on_caption_error 双模切换
     上游: CLI --allow_caption_fallback → fail_mode = NOT allow_caption_fallback
     传递链: main() → MarkdownLoader(fail_on_caption_error=fail_mode)
                       → ImageCaptioner(fail_on_error=fail_on_caption_error)
     位置: image_captioner.py:46-52
     逻辑:
       if self.fail_on_error:
           raise RuntimeError(...)     ← 中断整个 Pipeline
       else:
           return f"[图片: {alt}]"     ← 降级为占位文本

   【分支3】Markdown 清洗仅对 md/txt 执行
     位置: ingest_knowledge.py:158-162 + markdown_loader.py:25
     逻辑:
       if ext in ["md", "txt"]:
           → MarkdownLoader 内部调用 cleaner.clean()
           → 导出 debug_cleaned/ 文件
       else:
           → PDF/DOCX/XLSX Loader 直接解析，不经过清洗管道

   【分支4】DOCX 表格回退
     位置: docx_loader.py:38-51
     逻辑:
       if not blocks and doc.tables:   ← 没有段落时才解析表格
           for table in doc.tables:
               for row in table.rows:
                   构造 "表格第X行Y: 列1 | 列2 | ..."

   【分支5】代码块内/外 状态机
     位置: structure_normalizer.py:17-24 / code_block_marker.py:17-31
     逻辑:
       if line.strip().startswith('```'):
           in_code_block = not in_code_block
       if in_code_block:
           保持原样 / 合并为一行

   【分支6】短文本跳过切分
     位置: semantic_chunker.py:26-31
     逻辑:
       if len(text) < chunk_size * 0.5:  ← 短于 256 字符不切分
           final_chunks.append(block)     ← 原样保留

   【分支7】向量化失败零向量占位
     位置: embedder.py:39-42
     逻辑:
       try: emb = await embed_text(text)
       except Exception:
           embeddings.append([0.0] * 768)  ← 静默降级
